# PE/VC 项目财务分析工具

这个工具帮助投资实习生整理企业财报、合同和预算中的数字。它会记录每个数字来自哪里，生成一份需要人工核对的表；确认后，再计算基础财务指标、预测现金还能使用多久，并列出值得向企业追问的问题。

比如分析一家尚未有产品收入的研发型药企，可以重点看：每月花多少钱、现有现金能否支撑到下一研发节点、融资或临床进度推迟后会不会出现资金缺口。分析已有销售收入的企业，则可以看收入、毛利和营运资金等情况。

当前是 **v0.2 测试版**，只用虚构的合成样本验证过。它尚未用于真实项目，不能代替审计，也不会自动判断一个项目值不值得投资。

想了解具体操作，请看 [使用说明](使用说明.md)；想了解计算范围和限制，请看 [SKILL.md](SKILL.md)。仓库中的示例均为合成数据，尚未附代码复用许可证。
