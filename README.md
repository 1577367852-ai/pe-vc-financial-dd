# pe-vc-financial-dd

面向中国 PE/VC 项目财务材料的 Codex Skill v0.2 原型。它整理来源可追溯的财务科目，计算有限的基础指标、调整桥与现金情景，并生成需要核实的尽调问题。

当前公开版本**仅用于合成样本**，没有完成真实项目或生产环境验收。它不代替审计，也不自动给出投资结论。使用入口、口径及限制见 [SKILL.md](SKILL.md) 和 [使用说明.md](使用说明.md)。

仓库包含程序、测试和原始合成样本；不包含安装前的历史输出或已生成的示例结果。运行前须核对本机 Python、第三方库、写入位置及材料使用授权。测试运行会向仓库内 `outputs/` 和本机 QA 目录写入文件。

本仓库暂未附代码复用许可证。第三方工具及参考来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
